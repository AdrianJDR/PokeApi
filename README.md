Pokédex — Projeto com PokéAPI

## 📖 Sobre o projeto

Este projeto consiste em uma Pokédex desenvolvida utilizando HTML, CSS e JavaScript. A aplicação consome dados da [PokéAPI](https://pokeapi.co/), uma API gratuita que disponibiliza informações sobre os Pokémon, incluindo seus nomes, tipos, características e imagens.

Os dados utilizados pela aplicação são fornecidos pela [PokéAPI](https://pokeapi.co/).

O tutorial utilizado para fazer este projeto foi criado por [Carpi Coder](https://www.youtube.com/@carpicoder).

Vídeo: https://www.youtube.com/watch?v=EmxvMPcIy5c&t=37s

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, são praticados conceitos importantes para o desenvolvimento web:

- Consumo de APIs REST.
- Requisições HTTP com `fetch()`.
- Uso de Promises com `.then()` e tratamento de erros com `.catch()`.
- Conversão e leitura de dados JSON.
- Laços de repetição.
- Seleção e manipulação do DOM.
- Criação dinâmica de elementos HTML.

## Funcionalidades

- Listagem dos 151 Pokémon da primeira geração.
- Obtenção de dados diretamente da PokéAPI.
- Exibição dinâmica das informações dos Pokémon na página.
- Manipulação de elementos HTML através do JavaScript.
